# TellMeSensei v0.9.0-rc.1

TellMeSensei v0.9.0-rc.1 is the first release candidate for the provider
architecture refactor. It adds independently configurable AI providers for
Text and Vision, clarifies OCR configuration, and includes the language and
answer-window improvements merged since v0.8.2.

## Highlights

- Text and Vision now use a shared provider-neutral AI pipeline instead of a
  DeepSeek-specific service path.
- Text and Vision providers can be selected independently from **DeepSeek**,
  **Qwen**, and **Z.AI**, with curated model choices and a custom model ID option.
- API credentials and custom endpoints are stored per provider. Switching one
  capability no longer overwrites the other capability's provider or model.
- Settings can test Text and Vision independently. Vision validation sends an
  actual image input rather than treating a text-only response as proof of
  vision capability.
- OCR settings now distinguish the runtime mode (**Local** or **Online**) from
  the selected engine/provider. Existing Local OCR and Google Vision settings
  are migrated without changing their runtime behavior.
- The interface supports English and Simplified Chinese language preferences.
- Answer-window Context, Question, and Answer sections preserve readable
  proportions and typography at compact window sizes.

## Compatibility

- Windows x64
- macOS Intel x86_64
- macOS Apple Silicon arm64
- Existing DeepSeek, OCR, capture, cancellation, and Auto Watch workflows remain
  available through the shared application code.
- Existing `ocr_provider=local|google_vision` settings are migrated to the new
  OCR mode/provider representation.
- Local OCR remains the separately installed platform-specific component at
  **1.4.0** and is unchanged by this release candidate.

## macOS permissions and signing

macOS builds are ad-hoc signed and not notarized. Screen Recording permission is
required for capture and Auto Watch. macOS may require opening the application
from **Privacy & Security** with **Open Anyway**.
