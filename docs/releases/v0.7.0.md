# TellMeSensei v0.7.0

Release date: 2026-08-26

## Highlights

- AI Vision mode using `deepseek-v4-flash-vision-exp`
- Independent Text/OCR and Vision workflows
- Persistent floating controller
- Default shortcuts:
  - `Ctrl+Shift+A` for Text/OCR
  - `Ctrl+Shift+S` for Vision
- Vision retry and recapture
- Improved AnswerWindow readability
- Safer dual-hotkey rebinding
- Cross-platform release builds for Windows x64, macOS Intel, and macOS ARM64
- Unified Local OCR 1.4.0

## macOS

- Builds are ad-hoc signed.
- Builds are not notarized.
- **Open Anyway** may be required in **Privacy & Security**.
- Screen Recording permission is required for capture.
