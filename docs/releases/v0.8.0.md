# TellMeSensei v0.8.0

TellMeSensei v0.8.0 is the first stable release of Auto Watch, with
cross-platform display handling and lifecycle cleanup for dependable desktop
use.

## Highlights

- Auto Watch monitors a selected region on one screen for stable question
  changes and analyzes the latest question with Text/OCR or Vision.
- Latest-Wins dispatching keeps an older analysis from replacing a newer
  question. Auto Watch recovers after an individual error so later questions
  can still be analyzed.
- Pause, Resume, Analyze Now, and Stop are available during a watch session.
- On macOS, the Answer Window and Auto Watch mini controller remain visible
  while working in another application.
- Retina and non-integer device-pixel ratios are handled when mapping the
  selected ROI to screenshots. Display configuration changes are detected and
  handled without continuing with a stale mapping.
- Watch-session timers, pending work, overlays, and controllers are cleaned up
  on stop and application exit, while the shared Local OCR session remains
  available to the application.

## Compatibility

- Windows x64
- macOS Intel x86_64
- macOS Apple Silicon ARM64
- Local OCR 1.4.0 remains unchanged and is installed as a separate component.

## macOS permissions and signing

macOS builds are ad-hoc signed and not notarized. Screen Recording permission
is required for Auto Watch and manual capture. macOS may require opening the
application in Privacy & Security.

## Release assets

The Windows x64, macOS Intel, and macOS Apple Silicon formal builds will be
validated as part of the release process. Local OCR 1.4.0 remains an
independent installation and is not bundled with the Core application.
