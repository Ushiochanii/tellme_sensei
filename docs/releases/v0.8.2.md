# TellMeSensei v0.8.2

TellMeSensei v0.8.2 makes Auto Watch entry direct and consistent, adds manual
application updates in Settings, and includes capture and Local OCR reliability
fixes merged after v0.8.1.

## Highlights

- The floating controller now presents four unified entry cards: **Text / OCR**,
  **Vision**, **Watch**, and **Context Watch**. Each card uses a concise feature
  description and the controller keeps a compact status strip.
- **Settings → Shortcuts** configures all four global shortcuts together. The
  defaults are `Ctrl+Shift+A` for Text / OCR, `Ctrl+Shift+S` for Vision,
  `Ctrl+Shift+W` for Watch, and `Ctrl+Shift+C` for Context Watch. Duplicate
  shortcuts are rejected before saving.
- **Watch** starts screen selection immediately from its card or shortcut. After
  one region is selected, monitoring starts automatically.
- **Context Watch** starts with Context selection, advances automatically to
  Question selection, and starts monitoring after the second selection. There is
  no separate setup menu or manual Start action; Context and Question must be on
  the same display.
- **Settings → Auto Watch** stores the shared Text / OCR versus Vision analysis
  mode used by the next Watch or Context Watch session.
- **Settings → Updates** can manually check stable TellMeSensei GitHub Releases,
  select the matching package for the current platform, download it, and open the
  installer. Local OCR releases are kept out of the application update stream.

## Fixes

- Fixed Windows screen capture sometimes including the floating controller after
  it was hidden. Windows capture now waits for the launcher visibility change to
  settle and keeps a directly captured launcher hidden after the callback; the
  non-Windows capture path remains unchanged.
- Fixed persistent Local OCR startup failures being reduced to a generic invalid
  ready response. A worker's schema-valid startup error is now surfaced and the
  failed worker is terminated cleanly.
- Fixed Auto Watch selection metadata failures leaving the full-screen selection
  overlay open or leaving stale Context / Question workflow state behind.
  Cancellation and failure clear pending state, recoverable cross-display
  Question selections retry that stage, and stale callbacks are ignored.

## Compatibility

- Windows x64
- macOS Intel x86_64
- macOS Apple Silicon arm64
- Existing Text, Vision, OCR provider, cancellation, and Auto Watch session
  behavior remains shared across supported platforms. Context Watch selections
  are limited to one display.
- Local OCR remains a separate platform-specific component at **1.4.0**. It is
  not bundled into the application package and is unchanged by this release.
- Existing saved settings remain valid. New Watch and Context Watch shortcuts use
  their defaults when no value has been saved.

## Installation

Download the application package for the target platform from the [v0.8.2
GitHub Release](https://github.com/Ushiochanii/tellme_sensei/releases/tag/v0.8.2):

```text
TellMeSensei-Setup-0.8.2.exe
TellMeSensei-0.8.2-macos-x64.dmg
TellMeSensei-0.8.2-macos-arm64.dmg
```

Install Local OCR 1.4.0 separately from the [Local OCR
release](https://github.com/Ushiochanii/tellme_sensei/releases/tag/local-ocr-v1.4.0)
when on-device OCR is required. After installation, configure the DeepSeek key,
OCR provider, shortcuts, and Auto Watch analysis mode in Settings.

## macOS permissions and signing

macOS builds are ad-hoc signed and not notarized. Screen Recording permission is
required for Auto Watch and manual capture. macOS may require opening the
application in **Privacy & Security** with **Open Anyway**. Packaged-asset
validation remains separate from the source-tree workflow acceptance above.
