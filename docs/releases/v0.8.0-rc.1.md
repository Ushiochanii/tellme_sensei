# TellMeSensei v0.8.0-rc.1

TellMeSensei v0.8.0-rc.1 is a release candidate focused on Auto Watch and
release-level lifecycle, display, and packaging fixes.

## Highlights

- Auto Watch monitors a selected single-screen region for stable question
  changes and submits the latest question for Text/OCR or Vision analysis.
- Pause, Resume, Analyze Now, and Stop are available during a watch session.
- Latest-Wins dispatching prevents stale analysis results from replacing the
  current question.
- Auto Watch recovers after an individual OCR/API error so a later question
  can still be analyzed.
- Stop, cancellation, repeated shutdown, and application exit clean up the
  session-owned timer, coordinator, pending work, overlay, and mini controller.

## Phase 5 fixes

- Watch lifecycle cleanup now covers stop and application shutdown paths while
  preserving the shared Local OCR session for the rest of the application.
- Logical ROI coordinates are mapped to physical screenshots consistently for
  Retina and other device-pixel ratios, including clipped screen edges.
- A watch session detects screen removal or geometry/device-pixel-ratio changes
  and stops polling instead of continuing with a stale mapping.
- On macOS, the Answer Window and Auto Watch mini controller remain visible
  while the user works in another application.
- Packaging metadata and release assets take their version from the application
  version source; Core packaging includes the Auto Watch and NumPy runtime
  requirements without bundling the separate Local OCR component.

## Compatibility

- Windows x64
- macOS Intel x86_64
- macOS Apple Silicon ARM64
- Local OCR 1.4.0 remains unchanged and is installed as a separate component.

## macOS permissions and signing

macOS builds remain ad-hoc signed and are not notarized. macOS may require
opening the application in Privacy & Security. Screen Recording permission is
required to capture the selected region for Auto Watch and manual capture.

## Build and installation

Use Python 3.12 and install the Core/GUI development requirements:

```bash
python -m pip install -r requirements-dev.txt
```

Build the platform-native Core application from the corresponding host:

```bash
# Windows PowerShell
pwsh -File scripts/build_windows.ps1
pwsh -File scripts/build_installer.ps1

# macOS
bash scripts/build_macos.sh
bash scripts/package_macos_dmg.sh
```

Install the Windows per-user installer or open the macOS DMG and copy the
application to Applications. On first macOS use, grant Screen Recording
permission in System Settings > Privacy & Security > Screen Recording, then
restart the application if macOS requests it. Local OCR is installed and
updated separately; it is not part of the Core app or DMG.
