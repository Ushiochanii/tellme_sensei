# TellMeSensei v0.8.1-rc.1

TellMeSensei v0.8.1-rc.1 is the release candidate for Context + Question Auto
Watch. It adds a dual-region workflow while preserving the stable v0.8.0
Single Region, manual capture, cancellation, and lifecycle behavior.

## Highlights

- Select one shared Context region and one Question region on the same display.
- Analyze the first stable Context + Question pair, then re-analyze stable
  Context-only or Question-only changes without transient mixed pairs.
- Text/OCR keeps Context and Question distinct and reuses Context OCR while its
  revision is unchanged; Vision sends one in-memory composite image.
- Latest-Wins, cancellation, stale-result rejection, Pause, Resume, Analyze
  Now, Stop, and two-ROI Answer Window placement remain in the existing paths.
- Local OCR 1.4.0 is unchanged and remains a separate platform component.

## Compatibility and scope

- Windows x64
- macOS Intel x86_64
- macOS Apple Silicon arm64
- No cross-display or three-region monitoring, ROI persistence, browser/mobile
  support, or Vision two-stage redesign is included in this candidate.

## Build and installation

Use Python 3.12 and install the Core/GUI development requirements:

```bash
python -m pip install -r requirements-dev.txt
```

The existing platform-native release workflow produces:

```text
TellMeSensei-Setup-0.8.1-rc.1.exe
TellMeSensei-0.8.1-rc.1-macos-x64.dmg
TellMeSensei-0.8.1-rc.1-macos-arm64.dmg
```

No tag, GitHub Release, or formal RC build is created by this preparation
change; those actions wait for Supervisor acceptance.
