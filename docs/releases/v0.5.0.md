# TellMeSensei v0.5.0

## Highlights

- Lightweight Core application with PaddleOCR distributed separately.
- Explicit Local OCR and Google Cloud Vision OCR modes.
- Persistent Local OCR worker with engine reuse and conditional background
  prewarm.
- Settings for OCR provider, API keys, hotkey, and Local OCR component lifecycle.
- Windows portable and per-user installer builds.

## OCR modes

Local OCR keeps screenshots on the device and uses the separately installed
PaddleOCR component. Google Cloud Vision is an explicit online option; when it
is selected, screenshots are uploaded to Google Cloud Vision for recognition.
There is no silent Local-to-Online or Online-to-Local fallback.

## Local OCR

The Local OCR component is version `1.1.0` and can be downloaded from Settings.
Downloads use a pinned public release, SHA-256 verification, safe ZIP
extraction, a worker smoke test, and atomic activation. Remove and reinstall
are supported. The component is independent from the Core installer.

## Google Cloud Vision

Google Cloud Vision uses a user-provided API key. The Cloud Vision API must be
enabled for the user's Google Cloud project, and applicable billing or quota
requirements are the user's responsibility.

## Performance

Persistent worker reuse and background prewarm substantially reduce repeated
Local OCR startup cost. Warm OCR around 0.7 seconds and first OCR around 1
second after successful prewarm were typically observed in development testing;
these figures are not a performance guarantee.

## Installation

Install `TellMeSensei-Setup-0.5.0.exe` on Windows. The installer uses a
per-user location under `%LOCALAPPDATA%\Programs\TellMeSensei` and does not
require administrator privileges. After installation, open Settings to save
the DeepSeek key and choose an OCR provider. Local OCR is downloaded separately
and is approximately 255 MB compressed, with roughly 700 MB installed.

## Known limitations

- Windows only; macOS support is planned.
- The executable and installer are unsigned; Windows SmartScreen may show an
  Unknown Publisher warning.
- Local OCR requires a separate approximately 255 MB download and occupies
  roughly 700 MB after installation.
- Google Cloud Vision requires the user's own API key and an enabled API/billing
  configuration.
- There is no automatic application updater.
