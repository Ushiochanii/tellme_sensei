# TellMeSensei v0.8.1-rc.2

TellMeSensei v0.8.1-rc.2 is a follow-up release candidate for Context +
Question Auto Watch. It preserves the v0.8.1-rc.1 workflow and addresses the
packaged-runtime blockers found during RC1 Apple Silicon acceptance.

## Highlights

- Select one shared Context region and one Question region on the same display.
- Analyze the first stable Context + Question pair, then re-analyze stable
  Context-only or Question-only changes without transient mixed pairs.
- Text/OCR keeps Context and Question distinct and reuses Context OCR while its
  revision is unchanged; Vision sends one in-memory composite image.
- Latest-Wins, cancellation, stale-result rejection, Pause, Resume, Analyze
  Now, Stop, and two-ROI Answer Window placement remain in the existing paths.
- Local OCR 1.4.0 is unchanged and remains a separate platform component.

## RC2 fixes

- Packaged Google Vision and Local OCR HTTPS requests now use the native system
  trust store with a certifi fallback, restoring certificate verification in
  frozen applications and DMGs.
- Local OCR download failures and cancellations remain visible and actionable
  instead of being immediately replaced by a `Not installed` status.
- Settings includes a Debug page with a bounded, redacted runtime-log tail and
  a Refresh action, so troubleshooting does not expose common credentials or
  read an unbounded log file.

## Compatibility and scope

- Windows x64
- macOS Intel x86_64
- macOS Apple Silicon arm64
- No cross-display or three-region monitoring, ROI persistence, browser/mobile
  support, or Vision two-stage redesign is included in this candidate.

## Build and installation

Use Python 3.12 and install the Core/GUI development requirements:

```bash
python -m pip install -r requirements-dev.txt
```

The existing platform-native release workflow produces these RC2 artifact
names:

```text
TellMeSensei-Setup-0.8.1-rc.2.exe
TellMeSensei-0.8.1-rc.2-macos-x64.dmg
TellMeSensei-0.8.1-rc.2-macos-arm64.dmg
```

No tag, GitHub Release, or formal RC build is created by this preparation
change; those actions wait for Supervisor acceptance.

and is not overwritten or promoted by this preparation.
