# TellMeSensei v0.6.0

TellMeSensei v0.6.0 adds the macOS desktop application alongside the existing Windows release line.

## Highlights

- Native macOS Intel x86_64 support
- Native macOS Apple Silicon arm64 support
- Global hotkey and screen capture, including macOS fullscreen and Spaces
- Local OCR distributed as a separate platform-specific component
- Google Vision OCR as an explicit online OCR option
- Persistent Local OCR worker and prewarm support
- Screen Recording permission flow for macOS capture

## Downloads

- Windows stable binary remains [v0.5.0](https://github.com/Ushiochanii/tellme_sensei/releases/tag/v0.5.0).
- macOS Intel: [TellMeSensei-0.6.0-macos-x64.dmg](https://github.com/Ushiochanii/tellme_sensei/releases/tag/v0.6.0)
- macOS Apple Silicon: [TellMeSensei-0.6.0-macos-arm64.dmg](https://github.com/Ushiochanii/tellme_sensei/releases/tag/v0.6.0)

Local OCR components are downloaded separately:

- Windows x64: Local OCR 1.1.0
- macOS Intel x86_64: Local OCR 1.2.0
- macOS Apple Silicon arm64: Local OCR 1.3.0

macOS builds are ad-hoc signed and not notarized. macOS may require **Open Anyway** in **Privacy & Security**, and Screen Recording permission is required for capture.
