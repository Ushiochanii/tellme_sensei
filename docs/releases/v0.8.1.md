# TellMeSensei v0.8.1

TellMeSensei v0.8.1 is the stable release of Context + Question Auto Watch.
It extends the v0.8.0 Single Region workflow with a shared Context region and
a current Question region while preserving the existing manual capture, OCR,
Vision, cancellation, and lifecycle behavior.

## Highlights

- Select one shared Context region and one Question region on the same display.
- Analyze the first stable Context + Question pair, then re-analyze stable
  Context-only or Question-only changes without transient mixed pairs.
- Text/OCR keeps Context and Question distinct and reuses Context OCR while its
  revision is unchanged; Vision sends one in-memory composite image.
- Latest-Wins, cancellation, stale-result rejection, Pause, Resume, Analyze
  Now, Stop, and two-ROI Answer Window placement remain in the existing paths.
- Packaged Google Vision and Local OCR HTTPS requests use the native system
  trust store with a certifi fallback.
- Local OCR download failures and cancellations remain visible and actionable.
- Settings includes a bounded, redacted runtime-log tail with Refresh for
  troubleshooting.
- Local OCR 1.4.0 is unchanged and remains a separate platform component.

## Compatibility and scope

- Windows x64
- macOS Intel x86_64
- macOS Apple Silicon arm64
- No cross-display or three-region monitoring, ROI persistence, browser/mobile
  support, or Vision two-stage redesign is included.

## Installation

Download the package for the target platform from the [v0.8.1 GitHub
Release](https://github.com/Ushiochanii/tellme_sensei/releases/tag/v0.8.1):

```text
TellMeSensei-Setup-0.8.1.exe
TellMeSensei-0.8.1-macos-x64.dmg
TellMeSensei-0.8.1-macos-arm64.dmg
```

Local OCR 1.4.0 remains a separate download from the [Local OCR
release](https://github.com/Ushiochanii/tellme_sensei/releases/tag/local-ocr-v1.4.0).

## macOS permissions and signing

macOS builds are ad-hoc signed and not notarized. Screen Recording permission
is required for Auto Watch and manual capture. macOS may require opening the
application in Privacy & Security.
