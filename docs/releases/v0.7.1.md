# TellMeSensei v0.7.1

TellMeSensei v0.7.1 is a visual polish release for the Full desktop application.

## Highlights

- Redesigned floating controller
- Redesigned Answer Window
- Redesigned Settings interface
- Unified soft-glass visual language
- Improved Text / OCR and Vision mode presentation
- Improved settings navigation and OCR provider hierarchy
- Updated system tray menu and icon
- Consistent success, warning, error, and progress states
- No changes to OCR, Vision, prompt, model, or analysis behavior

## Compatibility

- Windows x64
- macOS Intel x86_64
- macOS Apple Silicon ARM64
- Local OCR 1.4.0 remains unchanged

## Notes

- macOS builds remain ad-hoc signed and not notarized.
- Screen Recording permission is required on macOS.
