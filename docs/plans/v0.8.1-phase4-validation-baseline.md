## Deliberately excluded local check

`tests/test_single_instance.py` was not run locally. The current restricted
sandbox does not permit the Qt `QLocalServer` endpoint required by those tests;
`AGENTS.md` therefore requires using the remaining Core suite locally and
treating GitHub Core CI as the authoritative validation for this file. This is
an environment limitation, not a product regression.
